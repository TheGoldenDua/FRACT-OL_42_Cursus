## 🧠 Overview

**Fract-ol** is a graphical project that allows students to explore the world of **fractals** and **computer graphics** using the **MiniLibX** library.  

The project involves implementing and visualizing fractals such as:
- **Mandelbrot set**  
- **Julia set**  
- **Burning Ship fractal**  

Students learn about **complex numbers, iterative algorithms**, and how to **render graphics in real time**, while practicing **event handling and pixel manipulation**.

---

## 🧩 Key Objectives

- Generate and visualize fractals efficiently  
- Use complex numbers to compute fractal iterations  
- Implement zooming and panning functionalities  
- Handle user interactions via keyboard and mouse  
- Understand graphics programming with MiniLibX
